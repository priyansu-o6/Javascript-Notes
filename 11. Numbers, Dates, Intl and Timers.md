## Converting and Checking Numbers
> 📝 **JavaScript Number Quirks:** All numbers in JavaScript are represented as **IEEE 754 double-precision 64-bit floats**. This means there's no separate integer type — integers are just floats without a fractional part.

**Key Implications:**
- Maximum safe integer: `Number.MAX_SAFE_INTEGER` = `9007199254740991`
- `0.1 + 0.2 !== 0.3` due to binary floating-point representation
- `Number.isFinite()` is the most robust way to check if a value is a valid number

> ⚠️ **Common Pitfall:** Never compare floating-point numbers directly. Use a tolerance: `Math.abs(a - b) < Number.EPSILON`.


```js
///////////////////////////////////////
// Converting and Checking Numbers
console.log(23 === 23.0); // → true (all numbers are floats)

// Base 10 - 0 to 9. 1/10 = 0.1. 3/10 = 3.3333333
// Binary base 2 - 0 1
console.log(0.1 + 0.2); // → 0.30000000000000004
console.log(0.1 + 0.2 === 0.3); // → false (floating point precision error!)

// Conversion
console.log(Number('23')); // → 23
console.log(+'23'); // → 23 (unary + triggers numeric conversion)

// Parsing
console.log(Number.parseInt('30px', 10)); // → 30 (stops at non-digit)
console.log(Number.parseInt('e23', 10)); // → NaN (starts with letter)

console.log(Number.parseInt('  2.5rem  ')); // → 2 (integer part only)
console.log(Number.parseFloat('  2.5rem  ')); // → 2.5 (keeps decimal)

// console.log(parseFloat('  2.5rem  ')); // Old global form (still works)

// Check if value is NaN
console.log(Number.isNaN(20)); // → false
console.log(Number.isNaN('20')); // → false (string is not NaN)
console.log(Number.isNaN(+'20X')); // → true (+'20X' evaluates to NaN)
console.log(Number.isNaN(23 / 0)); // → false (23/0 is Infinity, not NaN)

// Checking if value is number
console.log(Number.isFinite(20)); // → true
console.log(Number.isFinite('20')); // → false (strings are not finite numbers)
console.log(Number.isFinite(+'20X')); // → false (NaN is not finite)
console.log(Number.isFinite(23 / 0)); // → false (Infinity is not finite)

console.log(Number.isInteger(23)); // → true
console.log(Number.isInteger(23.0)); // → true (23.0 === 23)
console.log(Number.isInteger(23 / 0)); // → false (Infinity is not an integer)
```
- `Number.parseInt()` Number here provides something called "Namespace".

## Math and Rounding

```js
///////////////////////////////////////
// Math and Rounding
console.log(Math.sqrt(25));
console.log(25 ** (1 / 2));
console.log(8 ** (1 / 3));

console.log(Math.max(5, 18, 23, 11, 2)); // → 23
console.log(Math.max(5, 18, '23', 11, 2)); // → 23 (coerces string to number)
console.log(Math.max(5, 18, '23px', 11, 2)); // → NaN (cannot parse '23px')

console.log(Math.min(5, 18, 23, 11, 2)); // → 2

console.log(Math.PI * Number.parseFloat('10px') ** 2); // → 314.159... (circle area: πr²)

console.log(Math.trunc(Math.random() * 6) + 1); // → random integer 1-6 (like a die roll)

const randomInt = (min, max) =>
  Math.floor(Math.random() * (max - min) + 1) + min;
// 0...1 -> 0...(max - min) -> min...max
// console.log(randomInt(10, 20));

// Rounding integers
console.log(Math.round(23.3)); // → 23
console.log(Math.round(23.9)); // → 24

console.log(Math.ceil(23.3)); // → 24 (rounds UP)
console.log(Math.ceil(23.9)); // → 24

console.log(Math.floor(23.3)); // → 23 (rounds DOWN)
console.log(Math.floor('23.9')); // → 23 (type coercion works here)

console.log(Math.trunc(23.3)); // → 23 (removes decimal part)

console.log(Math.trunc(-23.3)); // -23
console.log(Math.floor(-23.3)); // -24

// Rounding decimals
console.log((2.7).toFixed(0)); // → '3' (returns string!)
console.log((2.7).toFixed(3)); // → '2.700' (pads with zeros)
console.log((2.345).toFixed(2)); // → '2.35' (rounds to 2 decimals)
console.log(+(2.345).toFixed(2)); // → 2.35 (unary + converts back to number)
```
- max function here actually does type coercion.
- `floor()` is little bit better than `trunc()` because it works in all cases no matter if we are dealing with positive or negative numbers.
- Primitives actually don't have methods. And so behind the scenes, JavaScript will do boxing. Boxing is to basically transform this to a number object, then call the method on that object. And then once the operation is finished it will convert it back to a primitive.

## Working with BigInt - ES2020
- The `BigInt` is a new primitive type that can represent whole numbers bigger than `253 - 1`, which is the largest number Javascript can reliably represent with the `number` type.
-   Append `n` to a literal integer or use `BigInt()` function to create a `bigint`.

```js
///////////////////////////////////////
// Working with BigInt
console.log(2 ** 53 - 1);
console.log(Number.MAX_SAFE_INTEGER);
console.log(2 ** 53 + 1);
console.log(2 ** 53 + 2);
console.log(2 ** 53 + 3);
console.log(2 ** 53 + 4);

console.log(4838430248342043823408394839483204n);
console.log(BigInt(48384302));

// Operations
console.log(10000n + 10000n);
console.log(36286372637263726376237263726372632n * 10000000n);
// console.log(Math.sqrt(16n));

const huge = 20289830237283728378237n;
const num = 23;
console.log(huge * BigInt(num));

// Exceptions
console.log(20n > 15);
console.log(20n === 20);
console.log(typeof 20n);
console.log(20n == '20');

console.log(huge + ' is REALLY big!!!');

// Divisions
console.log(11n / 3n);
console.log(10 / 3); // → 3.3333333333333335
```

## 📋 Cheat Sheet

| Task | Method |
|------|--------|
| Parse integer | `Number.parseInt('30px', 10)` |
| Parse float | `Number.parseFloat('2.5rem')` |
| Check NaN | `Number.isNaN(val)` |
| Check finite | `Number.isFinite(val)` |
| Random integer range | `Math.floor(Math.random() * (max - min + 1)) + min` |
| Future date | `new Date(Date.now() + 10 * 24 * 60 * 60 * 1000)` |
| Delay execution | `setTimeout(fn, ms)` |
| Repeat execution | `setInterval(fn, ms)` |
| Cancel timer | `clearTimeout(id)` / `clearInterval(id)` |

> ⚠️ **Common Pitfall:** `0.1 + 0.2 !== 0.3` due to binary floating-point representation. Use rounding for comparisons.
