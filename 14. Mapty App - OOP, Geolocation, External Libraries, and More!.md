## Project Overview
> 📝 **What We're Building:** Mapty is a workout tracking application that uses the browser's Geolocation API to pinpoint your location and the Leaflet library to display an interactive map. You can click anywhere on the map to log a running or cycling workout, and your data persists across page reloads using `localStorage`.

**Architecture Pattern:** This project uses a **class-based architecture** with:
- **App class:** Central controller managing state and UI
- **Workout classes:** `Running` and `Cycling` extending a base `Workout` class
- **Geolocation API:** Browser API for GPS coordinates
- **Leaflet:** Open-source library for interactive maps
- **localStorage:** Browser API for persistent client-side storage

> 🎯 **Learning Goals:** By building this app, you'll practice OOP inheritance, async geolocation, third-party library integration, and browser storage APIs.

> 📝 **The Geolocation API:** The browser exposes `navigator.geolocation` to access the device's GPS. `getCurrentPosition()` takes two callbacks: a **success handler** that receives coordinates, and an **error handler** for when permission is denied or GPS is unavailable.

## Using the Geolocation API

```js
if (navigator.geolocation) {
  navigator.geolocation.getCurrentPosition(
    function (position) {
      const { latitude } = position.coords;
      const { longitude } = position.coords;
      console.log(`https://www.google.pt/maps/@${latitude},${longitude}`);
    },
    function () {
      alert('Could not get your position');
    }
  );
}
```

## Displaying a Map Using Leaflet Library

> 📝 **Leaflet** is the most popular open-source JavaScript library for interactive maps. It's lightweight, mobile-friendly, and easy to extend.

```js
if (navigator.geolocation) {
  navigator.geolocation.getCurrentPosition(
    function (position) {
      const { latitude } = position.coords;
      const { longitude } = position.coords;

      const coords = [latitude, longitude];
      const map = L.map('map').setView(coords, 15); // 'map' is the container ID

      // Add OpenStreetMap tiles (the actual map imagery)
      L.tileLayer('https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png', {
        attribution:
          '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors',
      }).addTo(map);

      // Place a marker at user's location
      L.marker(coords)
        .addTo(map)
        .bindPopup('A pretty CSS3 popup.<br> Easily customizable.')
        .openPopup();
    },
    function () {
      alert(`Couldn't get the Location`);
    }
  );
}
```

## Displaying a Map Marker

> 📝 **Handling Map Clicks:** The map itself can listen for click events. When the user clicks anywhere, Leaflet provides a `mapEvent` object containing the exact latitude and longitude of the click via `mapEvent.latlng`.

```js
if (navigator.geolocation) {
  navigator.geolocation.getCurrentPosition(
    function (position) {
      const { latitude } = position.coords;
      const { longitude } = position.coords;

      const coords = [latitude, longitude];
      const map = L.map('map').setView(coords, 15);

      L.tileLayer('https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png', {
        attribution:
          '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors',
      }).addTo(map);

      // Listen for clicks anywhere on the map
      map.on('click', function (mapEvent) {
        const { lat, lng } = mapEvent.latlng; // Destructure click coordinates

        // Create a custom popup at the clicked location
        L.marker([lat, lng])
          .addTo(map)
          .bindPopup(
            L.popup({
              maxWidth: 250,
              minWidth: 100,
              autoClose: false,      // Popup stays open until manually closed
              closeOnClick: false,   // Clicking map doesn't close popup
              className: 'running-popup',
            })
          )
          .setPopupContent('Workout')
          .openPopup();
      });
    },
    function () {
      alert(`Couldn't get the Location`);
    }
  );
}
```

```js
  date = new Date();

  constructor(coords, distance, duration) {
    this.coords = coords; // [lat, lng]
    this.distance = distance; // in Km

  }
```

```js
  _setDescription() {
    // Prettier-ignore
    const months = ['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'];

    this.description = `${this.type[0].toUpperCase()}${this.type.slice(1)} on ${
```

|------|----------|
